## CopyTranslator acknowledgement

EnglishWordbook is an independently implemented Windows English-learning tool.

[CopyTranslator](https://github.com/CopyTranslator/CopyTranslator), created by
Elliott Zheng and the CopyTranslator community. We sincerely thank them for
their open-source contribution.

No CopyTranslator source files, bundled Electron code, icons, screenshots, or
binary assets are included in this repository. The application icon in this
repository is an original asset for EnglishWordbook.

## Third-party services

The app can send user-entered text to a model provider selected and configured
by the user, such as DeepSeek or Alibaba Cloud Model Studio. These services are
independent of this project. Users must comply with each provider's terms and
must never commit API keys to a repository.
